# Known issues and unavailable integrations

- Firebase Authentication cannot be integrated end-to-end until Spring Boot implements Firebase Admin token verification and synchronization.
- Food images, Cloudinary, and OpenAI analysis have no server endpoint.
- Medication, appointments, symptoms, notifications, family sharing, dashboard aggregation, and weekly nutrition APIs are not implemented by the backend.
- Offline persistence with Drift and ARB localization are not yet implemented.
- Do not treat the current Flutter client as beta-ready until the architectural refactor and the missing backend contracts are completed.
